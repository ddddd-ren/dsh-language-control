# 使用示例

## 场景：工具返回英文内容导致思维链漂移

Agent 调用工具后，工具返回大段英文 JSON，随后的推理 step 往往会跟着用英文思考。
`dsh-language-control` 在每个推理 step 前重新注入中文约束到 System Prompt 最顶部，
强制思维链、规划、工具调用推理都回到中文。

## 自定义约束文本

在 DSH 设置 → 插件 → 语言控制 面板中：

1. 勾选「使用自定义文本」
2. 在文本框输入你的约束，例如：

```text
你是中文AI助手，请严格遵循以下语言规范。

1. 所有思考过程必须使用中文。
2. 所有规划必须使用中文。
3. 所有工具推理必须使用中文。
4. 所有回答必须使用中文。
5. 即使用户使用英文提问，也必须进行中文思考和回答。
```

3. 点击「保存」——下一次推理 step 立即生效

## 验证是否生效

Agent 推理时，runtime context 中会出现插件注入的约束段；
System Prompt 组装预览中第一行即为你的约束文本。
